一句话 核心哲学

一注的分数 = 它携带了多少可验证的高质量信息。信息足、方向受独立信号确认、风险被排除 → 高分 → 该下；信息缺、方向矛盾、风险未排 → 低分 → 弃。分数是信息完整度与可靠度打分，不是「信心打分」——防止凭感觉下单，也防止为等信号错过已成型的单子。

总分公式 6 维相加

降水/变盘 ≤35 + 方向确认 ≤8 + 模型命中 ≤20 + 历史验证 ≤10 + 风险排除 ≤10 + 赔率价值 ≤5 = 总分

六维各有封顶。点开一场比赛，详情里每一维显示为 得分/满分，条越长越足。

≥80 加注 70-79 实单 60-69 候选 40-59 弱 <40 放弃
⚠️ 当前引擎实际满分约 76（方向确认按 8 分制、历史验证固定 6 分）。v1.5 档位下移：70-79 实单、≥80 加注。读分数看相对强弱，不是绝对刻度。

六维明细 怎么算

1降水/变盘满分 35
盘口的钱往哪边走、走了多少。「降水」= 赔率下降 = 机构买这个方向，是打分里最重的信号（历史命中 69%～73%）。
算法方向降水分量 D = 开盘价 − 临场价（只算投注方向；反向不奖）
四个候选胜平负主 / 胜平负客 / 让球主 / 让球客，取 降水最大且为正 的方向作为「降水方向」，这一维就按它给分
分档表 D≥0.5 → 35 · 0.40-0.49 → 32 · 0.30-0.39 → 29 · 0.20-0.29 → 26 · 0.10-0.19 → 22 · 0.05-0.09 → 15 · 0<D<0.05 → 10 · D=0 静盘 → 5 · D<0 反向升水 → 0
没有基线该场是开盘首盘（无快照可对比）→ 降水按 0 计，得分里看不到水分
2方向确认满分 8
多个独立信号源指向同一方向 = 交叉验证。当前引擎实现两个源，同向给足 8 分。
判定让球盘「降水方向」，与 胜平负低赔一侧（赔率最低的那边）同向 → 8 分；不一致 → 只给 4 分
数据来源竞彩官方：让球盘（hhad）+ 胜平负（had），同一次抓取
说明规则文档规划过 20 分制、含大众支持率/欧亚错配共 4 源；当前版本只落地前 2 源，满分为 8
2模型命中满分 20
当前形态是否命中历史回测验证过的模型 → 命中继承其胜率/EV。取最高命中，不叠加。全部未命中 = 0。
M1 P2a_gl1让球线 +1（主让一球，非深盘）+ 非五大 + 非次级联赛 + 降水方向为客队 + 降水 > 0.05 + 落在让球盘 → 20 分（历史回测 EV +172%）
降水规则让球盘 + 降水 ≥ 0.3 + 方向确认=2（同向） → 12 分（HAD 69% / HHAD 73% 命中线）
未命中0 分
2历史验证满分 10
当前形态在历史复盘里有没有同类支持。
当前版本固定 6 分（同类联赛/盘口/强弱结构有验证的基础档）
规划档位文档规划：回测明确为正 10 / 同类样本 6 / 少样本首次 2 / 历史反复失手 0（并升级进风险排除）——逐场落档尚未实现
2风险排除满分 10
从 10 分起逐个扣，扣到 0 为止。每命中一个历史踩过的坑就扣一档，坑越多越不值得投。
深盘|让球| ≥ 2（让球盘）→ −5（要净胜 3 球才穿盘，波尔图案例；结构风险，退回后也保留）
强强对话双方都是传统强队 → −2（一场论翻车高发）
次级低赔让球次级联赛 + 让球盘 + 主队方向 + 赔率 < 1.7 → −4（定价不稳无容错，格勒诺布/福伦丹案例；仅未退回时）
已移除深口高赔 −4（v1.4）：它只命中「退回」场，退回后投注已是胜平负，让球盘穿盘疑虑不再适用
2赔率价值满分 5
方向赔率的回报/风险比：赔率太低是死钱没赚头，太高又难中。
分档表 2.0-5.0 → 5（最优回报风险比） · 1.5-2.0 → 4 · >5.0 → 3（高赔难中） · 1.2-1.5 → 2（低赔死钱） · <1.2 → 0（无价值）
按哪个赔率按最终投注方向的赔率计：深盘退回的场按退回后的胜平负赔率（v1.4），不再用退回前的让球盘赔率虚高（见 FAQ）

常见疑问 FAQ

Q为什么画面显示「主负 @1.11」，赔率价值却是 0？
1. 引擎先扫四个方向找「降水最大」的方向 → 是让球+2客（2.65→2.37，跌 0.28），先按它的信号打降水/方向确认/模型分。
2. 但让球 +2 是深盘（主队要净胜 3 球才穿盘），系统铁律让球深口退回同侧胜平负，不打让胜/让负 → 投注方向改成主负 @1.11。
3. v1.4 起「退回」发生在打分前：价值（和依托赔率的风险规则）按退回后的主负 @1.11 重算 → 1.11 < 1.2 → 价值 0。
结论：1.11 的深盘大热，信号（降水）是有，但投注质量（赔率价值）是 0——信息足、没肉，这正是读分要看的。
Q为什么有些场次六维不全 / 没有分？
未开盘的场不参与打分；首盘（无基线快照）降水 0 分、但其余五维照常；历史日（只有盘口没有评分文件）不做评分。
Q分数多久更新一次、谁在打分？
网页只展示不计算。评分由刷新任务跑 score_sat_full.cjs 抓当日盘 → 合入平台 → 全表重算 → 落盘 data/scores/<日期>.json。刷新网页即看到新分数。
Q规则会变吗？
会。评分机制每天用真实结算结果喂养：每注复盘五问 → 定位打偏的维度 → 改算法/权重的版本号 +1，规则原文在 data/betting/scoring-system.md，升级记录在自我提升页。
