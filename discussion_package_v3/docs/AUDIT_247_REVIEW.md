## 2. 区间只能当粗略提示（更正）

之前给出的 `EV>0 ROI 95%CI −25%~+104%` 是用**平均赔率代替每场赔率**、按二项近似推出来的。

- 没有逐场赔率与逐场收益，**无法可靠计算真实 ROI 的方差**
- 该区间只能说明"9 场样本的 ROI 极不稳定"，**不能当作统计区间使用**
- 命中率的 Wilson 区间（35.4%~87.9%）是有效的，因为它只需要 n 和命中数

**正确表述**：EV>0 组 9 场中 6 场命中；样本量过小，无法确认优势；ROI 数值不可靠。

## 3. 分组数量合计 = 247 说明什么（更正）

它只说明**计数加总一致**，不能证明：
- 各组互斥（同一场可能被重复计入不同组）
- 分组口径正确
- 退款场、未结算场是否被正确排除

要证明互斥，必须拿到逐场 ID 并做交集检查。**目前无法证明。**
