# 竞彩模型库（Model Vault）

> **核心思想：模型矩阵自动分级，命中最强模型→顶格下注；小注搏冷；小注比分。**
> 每个模型独立判定、独立仓位、可回测、可复盘迭代。不下"感觉单"。

**单日封顶线（红线，永不突破）：**
- 单日累计投注 ≤ 现金30%
- 单日亏损 ≥ 现金20% → 当日停手
- 连输2单 → 重注层降档到2%，连赢3单回升
- **绝不满仓、绝不梭哈**

## M1 — P2a_gl1 完整命中（最强模型）

**信心：★★★（高） | 命中仓位：顶格8% ≈ 61元（起步期）**

### 触发条件（全部满足才触发）
1. **让球+1**（主队受让1球，客队让球）
2. **非单关**（bettingSingle=0，必须串关）——注意：命中唯一场次时需串另一腿，用第二强腿补
3. **非五大非次级联赛**（欧罗巴/欧协/葡超/德乙/荷乙/巴西杯/沙职/等）
4. **变盘1-2次**（开盘→临场，让球负方向被压1-2次）
5. **大众低估让球负**（机构让负概率 > 大众支持率，偏差 ≥ 10pp）

### 2026-08-27 精化（虚拟注验证后）
- **让球+1方向有效，让球-1方向无效**：
  - ✓ 普雷斯顿vs埃弗顿（让+1，大众低估）→ 0:4 埃弗顿大胜，让负中
  - ✗ 热刺/帕梅拉斯/达伽马（让-1）→ 全输
- **结论：M1只在"让球+1"方向成立，"让球-1"是陷阱**
- 另：大众低估让负是**必要条件**，若大众高估让负（如奥胡斯61% vs 机构47%）→ 诱盘，否决

### 排除条件
- 若大众高估让球负方向 → **否决**（诱盘嫌疑）
- 若客队首回合已领先（两回合制，次回合无大胜压力）→ **否决或降级**
- 若让负赔率 < 2.0 → **降级**（赔率太低不值全输风险）

### 历史验证
- 34注，胜率44.1%，精确EV 172.6%，ROI +288%，最大回撤27.2%

## M2 — 四维盘口验证

**信心：★★☆ | 命中仓位：5% ≈ 38元**

### 四维（全部采集）
1. **盘口方向**：HHAD vs HAD 隐含概率分歧
2. **大众支持偏差**：支持率API vs 机构概率
3. **历史样本**：同联赛/同类型让球盘历史穿盘率
4. **赛制/基本面**：杯赛轮换、两回合制、近况

### 触发条件
- 大众偏差 **≥19pp**（最强案例：费内巴切受让19.9pp → 直接客胜）
- 历史样本支持该方向
- 赛制无硬伤（无两回合领先方松懈、无杯赛轮换崩塌）

### 与M1的区别
- 不要求"让球+1"、不要求变盘——**偏差信号本身就是入场理由**
- 更适合发现"被大众错杀"的中低热度方向

### 2026-08-29 首败教训（bet-012）
- **bet-012 两腿全输（-38元）**：AC米兰让负2:0穿盘 + 水晶宫让胜1:4被曼城血洗
- **核心教训：M2在"实力悬殊"场次失效——强队穿盘是常态，大众偏差/近况波动拦不住实力碾压**
  - AC米兰近况虽差（输卡利亚里/乌迪内斯），但主场对弱旅威尼斯照样2:0穿盘
  - 曼城对水晶宫1:4，让1球盘直接血洗
- **规则升级：M2/M4 排除"实力差悬殊"场次**——当机构让球盘深度大（让1球+）且双方联赛/排名差距明显时，偏差信号不可靠
- 只搏"实力接近"场次的偏差错杀，不碰"强队深盘让球"的守盘幻想
- 关联：[[mistake-006]]（赛制/实力判断错误），[[disk-trap]]

## M3 — 冷门错杀

**信心：★☆☆ | 仓位：2% ≈ 15元 | 赔率2.5~5.0**

### 触发条件
- 大众低估 ≥15pp（机构概率 - 大众支持率 ≥ 15pp）
- 方向有基本面支撑（状态/历史/赛制）
- 赔率 2.5~5.0（搏冷要赔率够高）

### 案例
- 维京 vs 萨迪纳摩：客队过热(机构67% vs 大众实际低)，主胜2.23有价值 → 3:1 中 ✓
- 采列：势均力敌主胜2.2 → 1:1 平 ✗（**教训：实力接近时主队无价值，只有客队过热时才有效**）
- **bet-011 首败（2026-08-28，M3实战首次亏损）**：安德莱让负@3.15 × 奥胡斯让胜@2.95（2串1，stake15）
  - 触发逻辑：大众低估让球方向15-17pp + 首回合大胜方（安德莱0:3/本菲卡3:1）次回合无净胜压力，赌"松懈"冷门
  - 结果：安德莱3:0阿拉木图（让胜穿盘）、本菲卡3:1奥胡斯（让胜输）→ **两腿全输**
  - **教训：首回合大胜方"次回合松懈"剧本被击穿——实力差悬殊时领先方照样大胜，松懈不成立**
  - **规则升级：M3 的"两回合制松懈"逻辑废除，只搏"真实冷门"（实力接近+客队过热），不赌领先方松懈**
  - 触发需赔率≥2.5 + 大众低估≥15pp，两者都满足了仍输 → 说明"松懈"变量不可靠，须剔除该子逻辑

## M4 — 让-1陷阱反向

**信心：★☆☆ | 仓位：2% ≈ 15元**

### 触发条件
- 主队让1球（让球-1）
- 盘口让负方向大众高估（≥10pp）

### 案例（全错后总结的教训）
- 热刺让-2：查尔顿+2 → 5:1 热刺穿盘（让-1陷阱）✗
- 帕梅拉斯让-1：桑托斯+1 → 3:0 ✗
- 达伽马让-1：维多利亚+1 → 1:0 让平 ✗
- **教训：让球-1的让负是陷阱，主队在深盘让球时机构定价已覆盖，反向博（主队穿盘）才是价值**

## M5 — CRS高赔比分

**信心：☆ | 仓位：≤1%（≈7元） | 赔率≥8.0**

### 触发条件
- 只在大热场次博（主队≥80%大众支持）
- 博两个高赔比分（如 2:0 / 3:0 / 4:1 组合）
- 单注≤1%，**纯娱乐**，不指望盈利，命中了收益可观

### 纪律
- 每场至多2个比分
- 不因连续不中加注
- **不计入"连输降档"统计**（它是独立娱乐池）

## 下注决策流程（每天开盘/关盘执行）

```
1. 抓盘 → 逐场过 M1-M5 条件
2. 命中 M1 → 找第二腿串关 → 顶格8%下注
3. 命中 M2 → 5%下注（可串关或单关）
4. 命中 M3/M4 → 2%小注搏冷
5. 命中 M5 → ≤1%小注比分
6. 多模型命中 → 按仓位顺序下，但单日累计≤30%
7. 全部未命中 → 空仓（记录判断）
8. 每场未投注的 → 虚拟注（立场+理由+复盘钩子）
```
