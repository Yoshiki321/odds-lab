## 模拟与前向验证（第三章，只模拟不下单）
- 模拟≠真实：simulation.json 与 ledger.json（真实账本，保持 0 单）完全隔离；模拟永不提交订单。
- 赔率≠成交价：observedOdds 只是观察到的展示报价，不代表可成交、不可复制成交。
- 金额恒为 0 或 "SIM"，平台订单号恒为 null；风险检查沿用 100/1/3/5/20 上限做校验，只记录不执行。
- 预测不可变：predictions/YYYY-MM-DD_vN.json 写入后不得修改原文，改错只追加新版本保留历史；
  decisionId 去重，同赛事同市场同方向幂等；模拟赔率必须带 observedAt 时间戳。
- 数据质量：缺失赔率/时间/赛事 ID 拒绝记为有效预测；同一 observedAt 同一赛事只计一次（快照复用检出）。
- 结算：规则不明则 settlement.status 恒为“待确认”，绝不猜胜负、不猜盈亏（pnl 为 null）。
- 工具：tools/sim_ledger.cjs（校验/记账/快照/日报），测试：node tools/sim_test.cjs；日报见 reports/DATE.md。

## 定时守护（2026-11-19 落地）
- 单进程守护 `tools/ky_daemon.cjs`：每 30s tick；09:00 扫盘（当日未做才跑）；临场任务在 `[计划, 计划+5min]` 内执行一次，超窗记 missed 不补做。
- 单页铁律落地在代码里：复用同一标签页，多余页自动关闭；Edge/CDP 掉线会自动用固定 profile 重拉。
- 开机自启：Windows 任务计划 `KYDaemon`（用户登录时启动，隐藏窗口）。
- 状态 `runtime/daemon_state.json`；日志 `runtime/daemon.log`；扫盘计划 `sweep/plan_<date>*.json`；临场记录 `inplay/`。
- 自动流程**只观察+记录**，不下单；下单仍走人工批准的流程。
