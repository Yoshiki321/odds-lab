# 玩法与结算建模（分离版，2026-11-19）

> 原则：每种玩法独立建模，不互相替代；不能计算就输出"不可计算"，不猜、不补 0。

## 1. 竞彩普通胜平负（HAD）
- 方向：主胜 H / 平 D / 客胜 A（90 分钟含补时）
- 结果：命中 `win`，否则 `lose`；无走水
- 收益：`win → odds−1`；`lose → −1`
- 实现：`settleMoneyline`

## 2. 竞彩让球胜平负（HHAD）
- 符号：`goalLine` 为主队视角（-1 = 主让 1，+1 = 主受让 1）
- 结算：`adjHome = home + goalLine` 与 `away` 比较，三选一
- **关键**：让平 = **输**（不是走水）；只有欧亚结算才有走水
- 实现：`settleJcHandicap`

## 3. 开云全场独赢（欧洲盘 1X2）
- 方向：1 / X / 2
- 结果：`win` / `lose`，无走水
- 收益：`odds−1` / `−1`
- 实现：`settleMoneyline`（同一函数，赔率体系不同）

## 4. 亚盘让球（整数 / 半球 / quarter）
- 符号：主队视角，负数=主让，正数=主受让；客队取反
- 调整值：`adj = 视角净胜球 + 视角盘口`
- 整数盘：`adj>0` 赢 / `=0` 走水退本 / `<0` 输
- 半球盘：`adj>0` 赢 / `<0` 输（无走水）
- quarter（x.25/x.75）：拆两个子盘口 `L−0.25` 与 `L+0.25`，各半注
  - 赢+走水 = **赢半**（收益 `(odds−1)/2`）
  - 输+走水 = **输半**（损失 `0.5`）
  - 赢+赢 = 全赢；输+输 = 全输；走+走 = 走水
- 实现：`settleHandicap`

## 5. 大小球（整数 / 半球 / quarter）
- `over`：`adj = total − line`；`under`：`adj = line − total`
- 其余同上（整数走水、半球无走水、quarter 拆半）
- 实现：`settleTotal`

## 6. 走水与推盘的区分（易错点）
| 场景 | 竞彩 | 亚盘/欧亚 |
|---|---|---|
| 让 1 球，净胜 1 | **输**（让平） | **走水退本** |
| 大小 3，进 3 | 无此玩法（竞彩总进球按区间） | **走水退本** |
| quarter 一赢一走 | — | **赢半** |

## 7. 不可计算清单（安全失败）
- 非整数 HHAD 线（半球/quarter）→ `fairProbForPick` 返回 null
- 拟合误差 > 0.03 → null（不回退 1x2）
- 赔率缺失/≤1/NaN → null
- 概率和不为 1（容差 1e-6）→ null
- 整数盘 push 无法计算 → M-04 直接判"不可计算"

## 7.1 结算输入的规范化（2026-11-19 二次评审后）
- 合法盘口：0.25 的整数倍且 |line| ≤ 10；校验通过后**规范化为精确 0.25 倍数**再结算（消除浮点误差，避免走水被误判为赢）
- 比分必须非负整数；NaN/负数/小数一律 `uncomputable`
- 赔率必须有限且 ∈(1,1000)
- **大小球盘口不得为负**
- 竞彩让球线必须为整数，且同样先规范化
- 不可计算时 `pnlPerUnit = null` 并给出原因
