## 1. 每注期望 0.70 / 0.85（复算 §3.2）——通过（近似口径）

### 1.2 逐步计算

- 策略 A：p = 42/191 = 0.219895；EV/注 = 0.219895 × 3.18 = **0.699267 ≈ 0.70**；净 = 0.699267 − 1 = **−0.300733 ≈ −30.1%/注**（审计写 −30.0%，系先把 0.699 舍入到 0.70 再减 1 的路径差异，无实质差别，见更正附录说明 N1）。

结论：审计 §3.2 的 0.699 / 0.854 两行数字**复算通过**；“在给定规则下亏损是算术必然”的定性判断成立（负期望 × 固定比例复利）。

### 1.3 为什么“平均赔率 × 胜率”只是近似（必须声明）

精确的每注期望是逐注的联合均值 E[命中示性 × 该注赔率]，而 p × Ō = E[命中] × E[赔率]，两者**仅在“命中与否同该注赔率高低独立”时相等**。赔率方差越大、命中越向低赔注集中（2 串 1 里通常如此），p × Ō 的高估偏差越大。精确值应为逐注 `Σ返还_i / Σ本金_i`（变注额）或等注下 `Σ返还_i / N`。逐注赔率分布拿不到（非必读结果 JSON 未展开），故本节 0.70/0.85 **标注为近似值**，不标注精确。

### 1.4 与资金终值的关系（边界）

实盘是变注额复利（A：5%→连输降 3%，代码 L86–89；B：8%→5%/→8%，代码 L87/L157–164），每注期望 ≠ 资金增长率（还有波动拖累）。仅凭汇总数字**无法复算终值 80 / 409**（需要逐注本金序列与先后顺序）→ 终值数字标“未验证”（见 §4 总表）。

## 2. 连输 14 单 / 25 单概率（复算 §3.3）——定性通过，数字需更正

### 2.1 假设与方法（先写清）

- 总注数 N：A = 191，B = 211（skill L204）。
- 单注胜率 p：A = 42/191 = 0.219895，B = 34/211 = 0.161137；单注不中 q = 1 − p。
- 独立性假设：**独立同 p 近似**。实际两腿相关、冷门抱团（审计 §2.2/§4“能”第 6 条亦承认两腿不正交），真实过程若有正自相关，长连输会**更常见**——因此独立假设下的精确值是**下界（保守估计）**，方向说清：用独立假设反驳“连输异常论”是站得住的（即使在最不利于长连输的假设下，它依然常见）。
- 方法 A（审计原用）：窗口数 m = N − k + 1，q^k，P ≈ 1 − (1 − q^k)^m。**该式把重叠窗口当独立，是近似**；重叠窗口强正相关，且本参数下 m·q^k ≫ 1（A：5.50；B：2.31），结块（clumping）修正不可忽略——它会**系统性高估**，不能当下界用。
- 方法 B（本报告新增）：iid 精确递推（Markov：跟踪“当前连输 j<k 且尚未触达 k”的概率质量，n 步后 1 − 剩余质量 = 至少一次 k 连输的精确概率），无近似。另用 20 万次 Monte Carlo 交叉验证（A ≈ 0.7461、B ≈ 0.3310，与递推 0.746292/0.331493 一致）。

### 2.2 中间值（脚本输出，保留 6 位小数）

| | A（k=14） | B（k=25） |
|---|---|---|
| q | 0.780105 | 0.838863 |
| q^k | 0.030913 | 0.012367 |
| 窗口数 m = N−k+1 | 178 | 187 |
| 窗口独立近似 1−(1−q^k)^m | 0.996263（≈99.6%，与审计一致——审计算术无误） | 0.902420（≈90%，与审计“约九成”一致——算术无误） |
| **iid 精确递推** | **0.746292（≈74.6%）** | **0.331493（≈33.1%）** |

### 2.3 结论与更正

- 审计 §3.3 的算术（在其所选公式下）是对的：e 指数 −5.58/−2.33 复算应为 −5.589/−2.327，舍入层面的差异，结果 99.6%/90.2% 对得上。
- 但所选公式在本参数区偏差大：**A 应为约 75%（非 99.6%），B 应为约 33%（非约九成）**。详见更正附录 C1、C2（原文不动）。
- 定性结论不受影响，依然成立：74.6% 是“大概率事件”、33.1% 是“约三分之一、毫不罕见”——观察到的 14/25 连输都**不是“远超预测”的异常**；真正杀死资金的是负期望 × 高仓位。审计反驳 skill L244 的方向是对的，只是引用的两个概率数字夸大了。
- 适用范围：以上仅描述“在该样本量+该胜率下，长连输是波动常态”，**不证明未来**，不证明任何策略优劣。

## 3. 样本量功效（复算审计 §5.4 第 4 条“先算最小样本量”）——通过

### 3.1 先定义“检出优势”指什么

- H0：胜率 p0 = 25%；H1：胜率 p1 = 30%（单侧，H1: p > p0）。
- 显著性 α = 0.05（单侧；双侧对照一并给出）；功效 1−β = 0.8。
- 模型假设：二项独立同 p；正态近似公式 + 精确二项枚举双轨，公式与代入如下。
- 关键澄清：赔率固定 3.0 时，H0 下 EV = 0.25×3.0 = **0.75（净 −25%）**，H1 下 EV = 0.30×3.0 = **0.90（净 −10%）**——**两者仍为负**。所以这里“检出优势”仅指“有能力检出 5 个百分点的胜率差”，**达到注数 ≠ 盈利证明**，只代表对设定差值的检测能力（且即使检出 H1，在 3.0 赔率下期望依然为负）。

### 3.2 公式与代入（来源：单样本比例检验功效公式，Fleiss/Chow 标准式）

n = [(z_{1−α}√(p0(1−p0)) + z_{1−β}√(p1(1−p1))) / (p1 − p0)]²

- 单侧：z_{0.95} = 1.6449，z_{0.8} = 0.8416；分子 = 1.6449×√0.1875 + 0.8416×√0.21 = 1.6449×0.433013 + 0.8416×0.458258 = 0.712267 + 0.385671 = 1.097938；/0.05 = 21.9588；平方 = **482.17 → 向上取整 483 注**。
- 双侧对照：z = 1.9600 → **609.47 → 610 注**。
- 精确二项搜索（存在临界值 c 使实际 size ≤ 0.05 且 power ≥ 0.8 的最小 n）：**n = 494，c = 140，实际 size = 0.049639，实际 power = 0.803001**。

结论：审计 §5.4 “注数约数百量级才够；34 注、45 注量级只允许报告置信区间”**复算通过**（483/494/610 均为数百量级；精确二项比正态近似多约 11 注，属正常连续性修正量级）。
