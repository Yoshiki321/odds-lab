## 2. 数据与方法问题清单

逐项给"有 / 未见"判定，有则给证据，无则明写未见。

### 2.1 时间与时区 — 部分有（回测侧未见显式处理）

- 回测历史文件只有 `matchDate` 日期字符串，无开球时间戳（抽查 `data/history/football/2026-01-01.json`、`2026-03-01.json`、`2026-06-15.json`：每场仅 `matchDate/matchNumStr`，无 kickoff 字段）。
- `tools/strategy_a_backtest.js` L119-124、`tools/backtest_strategy_b.js` L108-111 用日期字符串分组并配对"当天+次日"场次；跨零点场次归属到哪一天**未定义**（未见）。
- `_odds_cache` 的 `updateDate/updateTime` 引擎只用相对顺序（`backtest_engine.js` L47 `history` 拼时间串但不做时区换算；`app/tools/score.ts` L192 实盘侧才算 `hoursToKO`）。
- 实验侧时区明确为 Asia/Shanghai（baseline 文件），回测侧无时区声明。**判定：回测侧时区处理未见，跨天配对存在归属歧义。**

### 2.2 未来信息泄漏 — 有（三处实锤，一处已部分缓解）

1. **选场赔率 = 终盘赔率（实锤）。** `.claude/skills/backtest-learning.md` L12 明写 `h/d/a` 为"终盘赔率"；`tools/strategy_a_backtest.js` L60-68 `isEligible` 用该终盘赔率卡 1.60-2.00 窗口，L186-188 又用**同一赔率**结算。选场与结算用的是同一个未来数。
2. **先全样本扫描选信号、再全样本回测（实锤，选择偏差）。** `tools/precise_backtest.js` L16-31 头注"P1-P8（训练+测试都EV>100%）"，L189 却在同一批 `all` 上做全量资金回测；`tools/deep_backtest.js` L6-13"S1-S8 从 deep_ev_scan 选前6"同样回测同一批。训练集选出的最优子集在全集（含训练集）上验证，ROI 系统性高估。
3. **`value_detector.js` 头注 ROI 无训练/测试划分（实锤）。** L26-40：P2a_gl1"精确EV 172.6%、ROI+288%（34注）"等数字无日期区间、无样本外标注；`data/model/model-vault.md` L50"M1 34注 ROI+288%"同源。34注量级的 +288% 不做样本外声明即当作"最强模型"写入决策流程（model-vault L140-148 顶格8%）。
4. **部分缓解（证据）。** `tools/cold_bet_v4_backtest.js` L142-150 球队亚盘记录只取 `r.date < beforeDate`（因果方向正确）；`tools/cold_bet_v5_backtest.js` L116-125 先算近况、L205 当轮结束后才更新积分（因果方向正确，但头注 L12-14 自认"排名由2026年累计积分近似、不完整"）。两处仍用终盘赔率定价，泄漏未根除。

### 2.3 同场多快照重复计数 — 策略B有风险，其余未见

- 策略A：有 `usedMatchIds` 去重（`strategy_a_backtest.js` L110/L128/L223-224），同场不重复。**未见重复。**
- 策略B：**有重复计数风险**。L104-137 按日期滑动"当天+次日"窗口选场，全程无 `usedMatchIds` 类集合，同一场可在连续两天被选中投注。注数 211 中含多少重复场**无法从报告反推**（`strategy_b_result.json` 非必读，未展开核对）。
- precise/deep/heavy/cold_v4/cold_v5：按场次顺序单遍迭代（precise L139、deep L165、heavy L305、v4 L160、v5 L112），一场比赛最多一注。**未见重复。**
- `app/tools/audit.ts` L21-25 用 `DISTINCT ON (match_id)` 取最早快照，信号口径正确。**未见重复。**

### 2.4 赔率时点（初盘 vs 即时 vs 终盘）— 有问题

- 历史文件每场只存一个 `h/d/a` 快照（skill 称之为终盘）；`_odds_cache` 有 `hadList/hhadList` 全序列，但回测引擎只取方向/次数（`backtest_engine.js` L36-48）或取 `last` 定价（precise L71 `hadLast`、deep L78-80 `hhadLast`）。
- **没有任何回测使用"开球时刻可投价格"**；`score.ts` 实盘侧用 `hadBase` 基线 + 实时快照算真降水（L77-113），但回测引擎从未接入该口径。**判定：有——终盘既选场又结算，买入价不可得性未处理。**

### 2.5 结算口径（让平算输 vs 走水退）— 有，且回测/实盘两套口径并存

- **回测侧：让平=输（有）。** `backtest_engine.js` L104-111（`homeAdj===as → 'D'`，再由调用方判负）；`backtest_strategy_b.js` L41-55（`settleLeg` 让球盘结果必须 `===pick` 才算赢，平即输）；`cold_bet_v4_backtest.js` L99-111、`cold_bet_v5_backtest.js` L57-68 同逻辑；precise/deep 把 D 当独立结果（仅当选中 D 才赢）。
- **实盘侧：已修走水（有）。** `app/tools/m04.ts` L1-2/L44-46：`EV = p_win×odds + p_push − 1`，自检含让+1回归用例（L59-64）。
- **Refund 口径矛盾（有）。** skill L18 要求跳过 `poolStatus="Refund"`，但 `backtest_engine.js` L73 放行 `Payout/Refund/''`（仅 L72 拦下空 `winFlag`）；precise L46-47、deep L42-44 不过滤 `poolStatus`。Refund 且有 `winFlag` 的场会被纳入回测，与 skill 口径不一致。
- 空赔率场（如 `2026-03-01.json` matchId 2037955 女足场 `h/d/a=""`、`poolStatus=""`、`winFlag=""`）：engine L71 `isNaN` 跳过 + L72 空 `winFlag` 跳过，双保险拦下。**该项未见问题。**

### 3.2 在给定规则下，每注期望为负——亏损是算术结果

- 策略A：0.2199 × 3.18 = **0.699**，即每下注1元期望拿回 0.70 元，**期望 −30.0%/注**。
- 策略B：0.1611 × 5.3 = **0.854**，即每下注1元期望拿回 0.85 元，**期望 −14.6%/注**。
- 在 5%/8% 固定比例复利下，191/211 注负期望重复下注穿仓，是该期望与该仓位的直接推论。**这句话成立，且只需要以上两行数字，不需要任何"数学必然"论断。**

### 3.3 "连输14/25单远超概率模型预测"——不成立，重算如下

skill L244 原话称"实际波动（连输14-25单）远超概率模型预测"。按**独立假设**重算（独立假设对被告最有利——若不独立，抱团冷门只会让长连输更常见）：

- 策略A：单注不中概率 q = 1 − 42/191 = 0.7801。q¹⁴ = 0.0309。191 注约 178 个窗口，至少出现一次 14 连输的概率 = 1 − (1−0.0309)¹⁷⁸ ≈ 1 − e^(−5.58) ≈ **99.6%**。
- 策略B：q = 1 − 34/211 = 0.8389。q²⁵ = 0.0124。211 注约 187 个窗口，至少出现一次 25 连输的概率 ≈ 1 − e^(−2.33) ≈ **90%**。

**结论：14 连输在 22% 胜率下几乎必然出现，25 连输在 16% 胜率下约九成概率出现。** 观察到的连输不是"远超预测"的异常，而是该胜率 + 该注数下的教科书式常态。真正杀死资金的是**负期望 × 高仓位**，不是异常波动。skill L244 的因果归因错了，L245"资金管理只能延缓死亡"的后半句（仓位过大加速死亡）才是对的部分。

|---|---|---|---|
| (a) 全策略空间证明 | 证明**所有**可选规则（含未试过的选场、单关、任意仓位）期望皆负 | 不满足。只试了 A/B 两套 2串1 规则；P1-P8/S1-S8 是单关信号且本身带选择偏差（§2.2）；单关对照组（heavy/cold 系列）用的是另一套选场，构不成"同一选场、仅拆串 vs 合串"的反事实 | precise/deep/strategy_a_backtest/strategy_b_backtest 各文件策略集合互不相同 |

### 3.5 本节结论（唯一被允许的措辞）

> 策略A/B **在该回测设定下（终盘口径选场+结算、让平算输、固定5%/8%复利、2026-01-01~08-25样本）观察到亏损且波动致死**。任何超出此限定域的表述——"2串1在数学上必然亏损""任何策略长期必输"（skill L157/L263-264）——均无证明支撑，**必须从 skill 文档中删除或改写为限定版**。

## 5. 样本外检验方案（可直接执行的步骤，不写代码）

1. **按时间切三段并上锁。** 如训练 2026-01-01~04-30、验证 05-01~06-15、样本外 06-16~08-25。规则与参数只能在训练段调、在验证段选一版**冻结成文**；样本外只跑一次，跑完不许回头改规则。
2. **用开球时可得价格。** 选场与结算统一用开球前最后可投快照（或首盘基线 `hadBase` 类口径）；终盘只用于"不可投对照组"。记录每场价格缺失率，缺失即剔除并披露剔除率。
3. **设市场基线对照。** 每注同步计算去水隐含概率（沿用 `score.ts` value 维口径：懂球帝欧赔去水），报告"策略 − 基线"的超额命中与超额 ROI，不只报绝对 ROI；另设等额随机对照组。
4. **先算最小样本量再开跑。** 二项比例单侧检验：如基线胜率 25%、要检出 30%（α=0.05、功效 0.8），注数约数百量级才够；34 注、45 注量级只允许报告**置信区间**，不允许下"有效/无效"结论。
5. **保守估计三件套。** (a) shrinkage：胜率/EV 向市场基线收缩后再算仓位；(b) 扣水位：回报统一扣减（如 ×0.95）再看是否为正；(c) 多重比较校正：若在验证段试过 P1-P8/S1-S8 多个子集，只承认校正后显著的，或只承认样本外段结果。
6. **输出固定报表。** 注数、胜率（含95%区间）、均赔、去水EV、资金曲线、最大回撤、最长连输、与基线差值；任一"样本外为负"即停用该规则，不得用"调参后重测"复活（重测即回到训练段，样本外作废重切）。
7. **口径对齐开云。** 让球按走水退款结算（含 p_push 项，沿用 `m04.ts` 口径）；金额按实验限额（单注≤1元、平台最小2元→当前为 0 真注）换算可执行性；不可执行的规则直接判"不可用"，不进回测。

## 6. 对 100 元实验的结论

### 6.1 前提（现状证据）

- 余额 100.00 元、未结 0 单、真实投注 0 单（`ledger.json` 为空账本；`README.md` 现状行）。
- `risk_config.json`：单注≤1元、日风险≤5元、累计≤20元、无杠杆、无加倍、无充值。
- 平台最小投注 2.00 元 > 单注上限 1 元 → `README.md`/`baseline` 已判定**停止真实下注**（stopReason）。**本报告维持该判定：继续 0 真注，只做模拟。**

### 6.2 模型与旧模块处置名单

**A. 可转用做观察特征（只记录、不触发真注、不进资金计算）：**

| 模块 | 可保留的观察点 | 红线 |
|---|---|---|
| `score.ts` value 维思路 | 欧盘去水概率 × 竞彩(开云)赔率 − 1 的 EV 算式（L295-312） | 必须用开云可比欧赔重标去水源；无欧赔可比时按 L309-312 回退为"价值未知"，**未知≠可投** |
| `m04.ts` 走水项 | 整数让球 `EV = p×odds + p_push − 1`（L44-46） | 结算价必须换成开云亚盘价重算 p_push；竞彩口径数字作废 |
| R5 时间窗概念 | 距开球 0.5~8h（`m04.ts` L32-34） | 按开云场次重验，不直接沿用阈值 |
| `computeDrawRisk` 思路 | 平局结构风险提示（`score.ts` L116-136） | 只做"放弃观察"，不做反向投注依据 |
| audit 方法 | 最早快照=信号、等额代理ROI、EV门分组（`audit.ts` 全文件） | 沿用方法，不沿用"EV>0=+39%"的数值结论（单赛季 247 场，见 §4"能"第8条） |

**B. 必须停用（模拟也不得作为下注依据，至多记"命中观察"）：**

| 模块 | 停用理由 |
|---|---|
| M1 P2a_gl1 完整（含顶格8%） | 三重竞彩锁死（bettingSingle=0、竞彩让球负三态、变盘1-2次官方序列）+ 仅34注 + 无样本外；model-vault L26-51 |
| M2 四维偏差 | 依赖竞彩 support 大众/机构概率数据源，开云侧无输入；另有 bet-012 首败记录（model-vault L73-80） |
| M3 冷门错杀 | 同上数据源缺失；"两回合松懈"子逻辑已自废（model-vault L96-101） |
| M4 让-1陷阱反向 | 文档自定"仅虚拟、不押真钱"（model-vault L105-118；score.ts L257-259 M4仅虚拟）；深盘定价在开云结构不同 |
| M5 CRS 比分 | 竞彩比分玩法，≤1%娱乐池；开云波胆赔率结构不同，不可比 |
| strategy_a / strategy_b 整套（含 5%/8% 资金） | 终盘泄漏 + 让平算输 + 固定高比例；在 100 元/单注≤1元/最小2元约束下数学上不可执行（5% 即 5 元 > 上限；最小一注 2 元 > 上限） |
| value_detector / live_signal 信号头注数字 | P2a_gl1"+288%"等无样本外小样本 ROI；live 当日快照 `hadChanges: 0`（`live_signal.js` L42），变盘条件在开云当日场景下恒缺失 |

### 6.3 一句话结论

> 旧模型无一样本外验证通过者 → 100 元实验**只模拟、零真注**；旧模块中仅 EV 算式、走水项、时间窗、平局风险、审计方法五个**思路**可降级为观察特征，其余（M1-M5 触发、2串1规则、5%/8%资金、终盘口径数字）全部停用。
