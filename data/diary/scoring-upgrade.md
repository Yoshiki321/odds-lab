## 一、系统规则（投前必读）

| # | 规则 |
|---|------|
| R1 | 官方数据优先——赛果/战绩/状态只来自官方数据，外部搜索只做背景，必须交叉验证 |
| R2 | 赛季边界检查——2026-08 月前的比赛是上赛季，不能当当前状态 |
| R3 | 投注前验证场次编号——必须在赔率数据中核对场次信息一致 |
| R4 | 8 维分析框架——每场必须覆盖赔率变化/冷门价值/体力伤停/变盘信号 |
| R5 | 时间窗口纪律——只投距开赛 ≥30 分钟且 ≤8 小时的比赛；超 24 小时不投 |
| R6 | 赛制认知——跨年(欧洲) vs 自然年(巴甲/日职/美职)，自然年写清轮次 |
| R7 | 分数优先——≥70 实单（5%）/ ≥80 加注（10%）/ 60-69 只虚拟，分数冲突时分数优先 |
| R8 | 实单方向=评分dir（用户09-06强化）——让-1 深口只是信号来源，实单按评分 dir 的胜平负盘口下注（主胜/主负），不买让球盘；受让(+1)可出让球盘 |
| R9 | 平局过滤器（09-07复盘 + GPT诊断落地）——让球走盘(push)不计 miss；**两阶段（v1.8 落码）**：平局结构险 R_draw≥0.7 弃投、0.5~0.7 方向降档只虚拟；R_draw = 平赔集中 + 让球浅 + 主客赔接近 三因子求和，只作用于真吃平局的敞口（裸胜平负 / 让球方），受让方（+1 盘平局=让球赢）豁免；滚动 2 天平局率 ≥35% → 方向信号整体降一档置信、实单线提高 5 分 |

## 四、复盘五问（每注必答，写入当日日记）

1. 高分注输了 → 哪个维度给了假高分？（降水骗/方向失灵/模型失效/风险漏排）
2. 低分注赢了 → 漏掉什么信息维度？当时可得吗？
3. 方向确认错 → 哪个信号源误导？（几个信号源里谁撒谎）
4. 降水方向对但没买到 → 执行问题还是分数门槛太高？
5. 模型命中但亏 → 模型真实 EV 是否已被行情修正？

症状 → 定位维度 → 改权重/加排除项 → 版本号 +1。同一维度 7 天内被打脸 2 次 → 强制降权重一档。
