# 信息值评分机制 (Scoring System)

- 版本: **v2.1**
- 建立: 2026-09-05（v1.0）→ 重构 2026-09-09（v2.0，S0 彻底重构）→ 09-09（v2.1，价值维独立欧赔源）
- 状态: 生效中（48-57 实单 · ≥58 加注 · 每日复盘升级）
- v2.0 依据：用户「彻底优化算法」+ S0 权重重构（22/12/22/12/22/10）+ 严格 EV 定调 + 09-05~09-08 档位校准回放
- v2.1 依据：用户 09-09 指出「赔率价值永远是 0」→ 官方去水概率同源循环（EV 恒−11%）
  → 接懂球帝 magicball 欧赔独立公平概率 → 让球线用 Skellam 泊松拟合（tools/ev-fit.ts）

## 0. 核心哲学

> **一注的分数 = 它携带了多少可验证的高质量信息。**

信息足、方向受多方独立确认、风险被排除 → 高分 → 该下。
信息缺、方向矛盾、风险未排 → 低分 → 弃。
评分不是"信心打分"，是**信息完整度与可靠度**打分——防止凭感觉下单，
也防止为等待信号而错过已经成型的单子。

**v2.0 最重要的语义变化：严格 EV。** 低赔大热即使信号齐，EV 为负 → 价值维≈0，
总分天然上不了高位——系统从"跟资金走"转向"只在正 EV 的场次重仓"。

## 1. 评分维度（6 维 · 100 分）

| 维度 | 权重 | 性质 |
|------|------|------|
| drop 降水/变盘 | 22 | 加分制 |
| confirm 方向确认 | 12 | 加分制（4 源） |
| model 模型命中 | 22 | 加分制（取最高，不叠加） |
| history 历史验证 | 12 | 加分制 |
| risk 风险排除 | 22 | 扣分制（从 22 起扣） |
| value 赔率价值 | 10 | 严格 EV |

### 1.1 降水/变盘（22 分）
**盘口资金用脚投票的强度。** 分量 16 + 形态 4 + 时间 2。

- 量级 16：方向降水 ≥0.5 → 16 / ≥0.4 → 14 / ≥0.3 → 12 / ≥0.2 → 10 / ≥0.1 → 8 / ≥0.05 → 6 / >0 → 4 / =0 静盘 → 2 / 升水 → 0
- 形态 4：方向侧 HAD 与 HHAD **同向变盘**且共 1-2 次 → +4；其他形态 → +2（无变盘 +0）
- 时间 2：距开赛 ≥6h → +2 / 2-6h → +1 / <2h → +0（临场追尾进 risk 另扣）
- 首盘无基线（`!`）→ 量级不给分（降水信号不可考），形态/时间照给

> v2.0 对比 v1.8：降水权重 35→22。上一版降水一维独大（35/100），靠它就能上 70；
> 重构后降水只是六维之一，靠单一信号推高分的路被堵死。

### 1.2 方向确认（12 分）
**多个独立信号源指向同一方向 = 交叉验证。** 4 源：

| # | 源 | 数据 |
|---|----|------|
| A | 竞彩 HHAD 盘口 | 让球盘低赔侧是否 = 投注方向 |
| B | 竞彩 HAD 欧赔 | 胜平负低赔侧是否 = 投注方向 |
| C | 大众支持率 | 支持率最高侧是否 = 投注方向 |
| D | 机构概率 | 去水概率最高侧是否 = 投注方向 |

- 4 源同向 → 12 / 3 → 10 / 2 → 7 / 1 → 4 / 0 → 0

**说明**：大众与机构同向 = 资金与赔率共振，最可靠；大众与机构背离 = 记矛盾不记支持。

### 1.3 模型命中（22 分）
**命中已验证模型 = 继承其历史胜率/EV。** 取最高命中，不叠加。

| 模型 | 触发 | 得分 |
|------|------|------|
| M1 P2a_gl1 | 让球+1 + 非五大 + 非次级 + 方向=客 + HHAD 降水>0.05 + 变盘1-2次同向 | 22 |
| M1 弱化 | M1 触发但变盘≥3次（已修正归零） | 16 |
| M1 弱化 | M1 触发但无变盘数据/非同向 | 18 |
| M2 四维偏差 | 大众偏差≥19pp + 方向=偏差侧 + 历史正 + **方向赔率≥2.0**（2026-09-09 加闸） | 18 |
| M2 偏差·历史未证实 | 同上但联赛历史未证实 | 12 |
| M3 冷门错杀 | 大众低估≥15pp + 赔率 2.5-5.0 | 12 |
| M4 让-1陷阱 | 深盘让-1 + 大众高估让负（仅虚拟，不押真钱） | 8 |
| 降水规则 | 方向降水≥0.1 且确认≥2源 | 10 |
| M5 CRS 比分 | 大热场（方向赔率≤1.5）博高赔比分（娱乐池） | 6 |

> **v2.0 校准两处**（2026-09-09）：
> 1. **M1 用 pick（原始候选）判定**，不用退回后的 market——让球+1客降水大量落入"深盘退回胜平负"，盘口仍是 HHAD。v1.8 的 卡尔马/埃尔切 两单实单命中即此形态，v2.0 重构时一度丢档，已修。
> 2. **M2 加 dirOdds≥2.0 闸门**——四维偏差=找被低估侧，1.3x 大热只是顺大众非偏差（严格 EV 已把大热价值打 0）。09-05~08 回放：M2 在大热上 0W2L（吉达联合@1.37/布伦特@1.52），全被闸门挡下。

### 1.4 历史验证（12 分）
**当前形态在联赛历史复盘中有没有支持。**

- 联赛基准样本：n≥20 → 6 / n≥10 → 4 / 有 → 2 / 无 → 1
- 平局高发联赛（drawRate≥33% → -4 / ≥29% → -2）只扣真吃平局的敞口（裸胜平负、让球方）
- 受让方（受让平局=让球赢）→ +2

### 1.5 风险排除（22 分，从 22 起扣）
| 排除项 | 扣分 |
|--------|------|
| 深盘（\|让球\|≥2）或 深盘退回胜平负 | -6 |
| 强强对话（双方都 STRONG 表） | -3 |
| 次级联赛低赔主场（HHAD 主、方向赔率<1.7） | -5 |
| 平局结构（R_draw ≥0.5 → -4 / ≥0.35 → -3 / ≥0.2 → -2，只扣吃平局敞口） | -2~-4 |
| 临场追尾（距开赛<2h 且方向降水≥0.2） | -3 |
| 大众拥挤（单边支持率≥70%） | -2 |
| 全局平局杠杆（滚动 2 天平局率≥35% 且样本≥8） | -3 |

最低扣到 0。多风险叠加 = 该场天然不值得投。

### 1.6 赔率价值（10 分，严格 EV · v2.1 独立欧赔源）
**value = 欧洲市场公平概率 × 竞彩方向赔率 − 1。**

- **独立概率源（v2.1 新增）**：懂球帝 magicball 欧赔（`score_odds.spot[1]`），去水后得公平 1x2 概率
  （主/平/客）。HAD 方向直接用该侧公平概率；**HHAD 让球线** 由公平 1x2 拟合独立泊松强度
  （`tools/ev-fit.ts`，Skellam 边差分）求 `P(主进球−客进球 + 主让球线 > 0)`，让球线符号先统一再算概率，避免主让深盘被错误算成 P99%/P9%。
- EV 分档（v2.1）：EV ≥ +8% → 10 / ≥+4% → 8 / ≥0 → 6 / ≥-4% → 4 / ≥-8% → 2 / 更差 → 0
- 无欧赔可比（magicball 未覆盖）→ 赔率 1.6-5.0 给微基础分 2-3（不鼓励无信息投注）
- 数据流：`refresh` 每轮抓 magicball → PG `europe_odds`（覆盖式快照）→ scoreDay 注入 → value 维度

> **v2.1 弃用官方去水概率**：竞彩支持率去水概率与竞彩赔率**同源**，EV 恒 = −11%（循环）。
> 改独立欧赔后 value 才真正区分场次——奈梅亨客+1@2.19 欧EV +12.8%（10 分），
> 皇马主胜@1.4 欧EV −14%（0 分）。这是用户 09-09 定调「赔率价值不能永远 0」的落地。
> **严格 EV 的含义**：买低赔大热 ≈ EV 为负 → 价值维≈0。系统只在真正超值的场次给价值分。

### 1.7 平局两阶段（R_draw · v1.8 落码 → v2.0 扩为 5 因子）

> 痛点：09-06 周日场 9/24 平局把主胜/主负方向信号全灭。
> 原则：平局是第三结果，应先于方向建模；弃投通常比机械降分干净。
> 平局风险只作用于真吃平局的敞口（裸胜平负 HAD、让球方）；受让方豁免。

**R_draw 平局结构险**（0~1，5 因子，每项从实际盘口可得）：

| 因子 | 条件 | 分 |
|------|------|----|
| 平赔集中度 rOdds | 欧赔平赔 <3.0 / <3.2 / <3.4 / <3.6 | 0.4 / 0.3 / 0.2 / 0.1 |
| 让球浅度 rLine | 平手盘 / ≤+0.5 / ≤+1 | 0.3 / 0.3 / 0.2 |
| 主客赔接近度 rClose | 主客欧赔差 ≤0.5 / ≤1.0 | 0.3 / 0.2 |
| 联赛平局基准 rBase | 联赛 drawRate ≥33% / ≥29% | 0.25 / 0.15 |
| 盘口分歧 rSplit | HAD 低赔侧 ≠ HHAD 低赔侧 | 0.2 |

**阶段A**：R_draw ≥ 0.7 → **弃投**（band=❌弃投·平局，总分压至 ≤47）
**阶段B**：0.5 ≤ R_draw < 0.7 → **只虚拟**（总分压至 ≤47，band=⏳候选·平局）
R_draw ≥0.5 的场 band 带「·平局」标记，总分即单事实源，任何消费方都当弃投/只虚拟。

> 受让方（受让平局=让球赢）R_draw=0 豁免，不参与两阶段。

**已知代价（09-09 校准确认）**：埃尔切（09-08 实单命中，主负@1.89 2:3 赢）R_draw=0.75
（平赔集中 3.27 + 让球浅 +1 + 西甲 32% 平局基准 + 盘口分歧）→ v2.0 会把它弃投。
这是平局过滤器的设计成本：宁可错过一注赢，不接一注 37.5% 平局潮。伯明翰/帕尔马 09-06
双 2:2 灭实单即此类，过滤器整体为正。

## 2. 总分与档位（v2.0 校准）

```
总分 = 降水22 + 方向12 + 模型22 + 历史12 + 风险22 + 价值10
```

| 档位 | 分数 | 动作 |
|------|------|------|
| 🔨 加注 | ≥58 | 顶格仓位（起步期 10%） |
| ✅ 实单 | 48 ~ 57 | 正常档下注（起步期 5%） |
| ⏳ 候选 | 40 ~ 47 | 只虚拟，继续盯临场 |
| 👀 弱 | 30 ~ 39 | 只虚拟，不投入分析时间 |
| ❌ 放弃 | <30 | 放弃 |

> **为什么档位从 v1.8 的 80/70/60 下移到 58/48/40**（2026-09-09 校准回放）：
> 严格 EV 把低赔大热价值维打 0，v2.0 实际分布压缩到 26~58（v1.8 是 60~76）。
> 按 09-05~09-08 已开奖 44 场回放，锚点（实单命中的 卡尔马 58=加注 / 埃尔切 49 被 R_draw 弃投）
> 必须落在实单+。档位由"全表命中率随分数单调"校准：
> ≥48（实单+加注）1W0L·4 未开 → 100%；40-47（候选）约 45%；<40 约 41%——真实档位分离已建立。
> **档位是临时校准值，每周随结算数据复核。**

单日累计仍受 30% 封顶、单日亏损 20% 停手、连输 2 单降档约束（策略 v4 不变）。

## 3. 执行流程（每日）

```
[开盘 13:00]  抓盘 → refresh_scores(v2) → 全表打分排序 → ≥48 实单 / ≥58 加注 → 记录判断
[临场 17-20]  复扫降水/变盘 → 重算分 → 分数涨过 48 的场补单
[关盘 23:00]  终版打分存档（当日评分快照）
[凌晨结算]    官方结果 → 每注: 得分 vs 结果 → 生成复盘记录
[每日复盘]    见 §4，升级机制版本 ++
```

## 4. 每日复盘升级循环（铁律）

> **评分机制不是写死的，是每天用结算结果喂养的。** 复盘不只复盘注单，也复盘机制本身。

### 4.1 机制复盘五问（每注必答）
1. **高分注输了** → 是哪个维度给了假高分？(降水骗 / 方向确认失灵 / 模型失效 / 风险漏排)
2. **低分注赢了** → 漏掉了什么信息维度？(该信息当时可得吗?)
3. **方向确认错** → 哪个信号源误导了？（四点里谁撒谎）
4. **降水方向对但没买到** → 执行出问题还是分数门槛太高？
5. **模型命中但亏** → 该模型的真实 EV 是否已被行情修正？（需更新 model-vault）

### 4.2 升级动作
- 症状 → 定位维度 → 改权重/加排除项/调公式 → 版本号 +1
- 每次升级记录：日期、旧版本号、变更内容、复盘依据（哪一注哪一维打脸），
  写入本文件 §5 版本历史 + `data/betting/scoring-log.md`
- 同一维度 7 天内被打脸 2 次 → 强制降权重一档
- 权重改动后，用**近 30 天已结算注单**（真注+虚拟注）批量回打一遍，确认不误伤再定稿

### 4.3 权重上限保护
- 任何单维度权重上限：降水 25 / 方向 15 / 模型 25 / 历史 12 / 风险 25 / 价值 12
- 任何维度不允许通过"全给满"推高分——必须真实拿数据换分
