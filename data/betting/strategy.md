# 投注策略与纪律

## 总纲

**唯一目标：不要输光。** 意思是不允许出现把本金清零的极端行为，宁可少赢不可多输。

## 资金纪律（硬性）

1. 单笔投注 ≤ 当前现金的 **10%**（资金下降→投注额跟着降，下降保护）。
2. 单日累计投注 ≤ 当前现金的 **30%**。
3. 无论多看好都不加杠杆、不融资、不 panic 追注。
4. 连输之后**强制降注**：连输 2 单后单笔上限降到 5%。

## 选场纪律

1. **只投开赛时间充裕的场次**（至少在开赛前 30 分钟下单），绝不投已开赛/即将开赛。
2. **只投经过分析档案验证的场次**：赔率 + 双方状态 + 让球合理性。
3. **串关只做 2 串 1**，绝不 3 串及以上（单场胜率 ~50% 时 3 串 1 只有 ~12% 命中率）。
4. 优先投**让球盘赔率 ≥ 1.7** 的场次（容错，赔率太低不值得冒全输风险）。
5. 每场只投一个结果，不搞双选摊薄。

## 模型矩阵分级下注（v3，2026-08-27 重构）

> v3 升级：从"8维分析 + 全有或全无下注"重构为**模型矩阵自动分级**。每个模型独立判定、独立仓位。命中最强模型→顶格下注；小注搏冷；小注比分。**不下"感觉单"。**

### 模型判定要点（踩坑后固化的规则）

**M1 变盘条件：** 变盘1-2次 = 资金没介入、庄家没修正。变盘3次+已修正，价值消失。**大众低估让负是必要项**，若大众高估让负（61% vs 47%）→ 诱盘，否决（奥胡斯案例）。

**M2 偏差信号：** 大众偏差 ≥19pp 是最强（费内巴切19.9pp→直接客胜）。偏差越大方向越可靠。不需要变盘。

**M3 冷门：** 只在**客队过热**时主队有价值（维京✓）；**实力接近时主队无价值**（采列✗）。赔率2.5-5.0才搏。

**M4 让-1陷阱：** 主队让1球+大众高估让负 → 反向博主队穿盘。让球-1的让负是陷阱（热刺/帕梅拉斯/达伽马全错）。

**M5 比分：** 独立娱乐池，≤1%仓位，不计入连输降档统计。大热场（≥80%大众）博2:0/3:0等。

### 下注决策流程

```
1. 抓盘+支持率 → 逐场过 M1-M5
2. 命中 M1 → 串第二腿 → 顶格10%
3. 命中 M2 → 5%
4. 命中 M3/M4 → 2%搏冷
5. 命中 M5 → ≤1%比分
6. 多命中 → 按仓位下，单日累计≤30%
7. 全未命中 → 空仓（记录判断）
8. 每场未投注 → 虚拟注
```

### 单日封顶线（红线，不可违反）
- 单日累计投注 ≤ 现金 **30%**
- 单日亏损 ≥ 现金 **20%** → 当日停手
- 连输2单 → 重注层降档到2%
- **绝不满仓、绝不梭哈**

## 结算纪律

- 赛后永远用**官方开奖结果**结算，不猜。
- 结算赔率 = **投注时刻的赔率**（写入 bet 档案，不随赛前变化）。
- 结算后更新 ledger + bankroll，单笔 bet 档案标记 `status: settled`。
## 信息值评分制（v4，2026-09-05 用户定调）

> v4 升级：模型矩阵之上加**统一信息值评分**作为下注门槛。所有候选场次逐场打分（100分制），**≥80 上实单，≥90 重锤（顶格仓位）**。模型命中、降水分量、方向确认都是加分项；信息不足=低分=放弃。不再"看着顺眼就上"。

### 评分维度与版本

> **完整机制见 `data/betting/scoring-system.md`（版本化，每日复盘升级）。**
> 工具：`node tools/score_sort.cjs`（自动读版本号；`--detail` 看维度明细，`--csv` 导出复盘）。
> 复盘升级日志：`data/betting/scoring-log.md`。权重改动必须用近30天已结算单回打验证。

**6 维 100 分 + 变盘加计**：
| 维度 | 满分 | 一句话 |
|------|------|--------|
| 降水/变盘信号 | 35 | 方向降水分量 D（≥0.5=35，越深越高；反向=0）+ 变盘1-2次加计≤3 |
| 方向确认 | 20 | 4 源同向（竞彩HHAD/HAD/大众/欧亚错配）：4点=20 / 3点=16 / 2点=12 / 1点=4 |
| 模型命中 | 20 | M1=20 / M2=16 / M3=13 / 降水规则=12 / M5=6，取最高 |
| 历史验证 | 10 | 直接回测=10 / 同类=6 / 少样本=2 / 打脸=0 |
| 风险排除 | 10 | 陷阱-5 / 深盘-3 / 强强-2 / 客场巨热-2 / 远期-2 / 体力-2 |
| 赔率价值 | 5 | 2.0-5.0=5 / 1.5-2.0=4 / >5.0=3 / <1.5=2 |

### 档位与执行
- **≥90 重锤**：顶格仓位（起步期10%），直接实单
- **80-89 实单**：正常档下注
- **60-79 候选**：保持虚拟注，盯临场，分数随盘口变化重算
- **40-59 弱信息**：只虚拟，不实单
- **<40 放弃**：不看

### 执行纪律
1. 每次开盘/关盘扫描，跑一次 score_sort.cjs，全表排序汇报
2. 实单只在评分达标场次里选；模型矩阵与评分制冲突时**以评分制为准**
3. 全部场次必须出现在评分表里（无一遗漏，包括"放弃"档）
4. 评分是当日时点快照——盘口变了分数就变，临场复扫以最新为准
5. 虚拟注铁律不变：每场未投注仍虚拟下注复盘
