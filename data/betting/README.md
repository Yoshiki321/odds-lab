# 竞彩投注记录体系

本金：**1000 元**（起始）
目标：**不要输光**（资金管理 > 胜率）

## 目录结构

```
data/betting/
├── ledger.json          # 总台账（资金、累计盈亏、当前持仓）
├── bankroll.json        # 资金流水（每一笔充值/投注/结算）
├── strategy.md          # 投注策略与纪律
├── bets/                # 每笔投注独立档案
│   └── bet-{id}.json
└── analysis/            # 单场分析档案
    └── {matchId}.json
```

## 核心规则

1. **绝对不接已开赛**：投注必须以 `开赛时间 > 投注确认时间` 为前提，写入每笔投注档案。
2. **单笔投注 ≤ 总资金的 10%**（打赢概率有限的游戏里重注=自杀）。
3. **单日累计投注额 ≤ 总资金的 30%**，留足缓冲。
4. **只投我们自己独立分析过的场次**，分析档案逐场建立。
5. **结算必须用官方开奖结果 + 成交时的赔率**，赛后手工执行 `settle.js`。

## 玩法说明（竞彩）

- **胜平负 (HAD)**：就是单场主胜/平/客胜赔率。本模拟中多数场次不能单关，需 2 场+ 串关。
- **让球胜平负 (HHAD)**：主队让出 goalLine 球后再结算胜平负。
- **串关**：2场+ 串一起，奖金 = 各场赔率相乘 × 投注额；**任一场不中则整单全输**。
