# 滚球虚拟单审计规则（我定，2026-11-19）

## 目的
用零成本验证"滚球小联赛盘"是否存在可盈利优势，再决定是否恢复真实滚球。

## 记录口径
- 来源：`tools/ky_virtual_live.cjs`（每 2 分钟一轮）
- 只做抽水总和 < 1.07 的独赢/让分盘；每轮最多 2 单；虚拟本金 2 元
- 结算：比赛从滚球列表消失后用最后可见比分判定；无比分记 void
- 存储：`virtual/live_virtual.json`

## 判定门槛（先写死，跑完再改）
1. **第一道粗筛（n=30）**
   - 胜率 < 45% → 直接判"滚球无优势"，永久停真实滚球
   - 胜率 ≥ 55% → 进入第二阶段
   - 45%~55% → 继续积累到 100 单，不做结论
2. **第二阶段（n=100）**
   - 用 Wilson 95% 置信区间下界 > 保本胜率（按平均赔率算）→ 认为可能有优势，才允许小额真实滚球
   - 置信区间下界 ≤ 保本胜率 → 判无优势，停
3. **保本线**：`1 / 平均赔率`（1.85 → 54.1%；1.90 → 52.6%）

## 其它约束
- 真实滚球即使恢复，单注 ≤2 元、未结 ≤5、当日 ≤5、累计亏 ≤20
- 虚拟单结论只用于"是否恢复真实"，不用于"加注"
- 任何结论必须附样本量、胜率、置信区间、平均赔率；样本不足就写"证据不足"
