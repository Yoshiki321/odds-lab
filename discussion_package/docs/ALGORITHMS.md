# 算法清单（实际在用的，2026-11-19）

> 两个体系：**竞彩侧（有 EV 模型）** 与 **开云侧（目前只有抽水与保本计算，无模型）**。分开写，不要混。

---

## A. 去水（de-vig，比例法）

给定一组十进制赔率 `O_i`（i=主/平/客，或 大/小，或 主/客）：

```
inv_i   = 1 / O_i
Z       = Σ inv_i
vig     = Z - 1                      # 抽水率
fair_i  = inv_i / Z                  # 去水后公平概率（和为 1）
```

**保本胜率**：单注赔率 O，保本需 `p_breakeven = 1 / O`。

**示例**（曼城 1.37 / 平 5.00 / 富勒姆 6.40）：
```
inv = 0.7299, 0.2000, 0.1563 → Z = 1.0862, vig = 8.62%
fair = 主 67.2% / 平 18.4% / 客 14.4%
主胜保本需 1/1.37 = 73.0% → 公平概率只有 67.2% → 负 EV
```

## B. 从欧赔反推进球强度（竞彩侧 EV 的核心）

比例去水只给 1x2 三项概率，**不能给让球盘概率**。项目用独立泊松 + Skellam 差分拟合：

1. 设主队进球 `H ~ Poisson(λh)`、客队 `A ~ Poisson(λa)`，相互独立。
2. 净胜球 `M = H − A` 服从 Skellam(λh, λa)：
   ```
   P(M = m) = Σ_j Poisson(j; λh) · Poisson(j − m; λa)
   ```
3. 网格搜索 (λh, λa)，最小化与去水 1x2 的偏差：
   ```
   err(λh, λa) = |P(M ≥ 1) − fair_home| + |P(M ≤ −1) − fair_away|
   λ 网格 0.2~3.6，步长 0.1，再 0.01 局部精化两次
   若 err > 0.03 → 判定拟合失败，回退到 1x2 侧概率
   ```

## C. 让球盘公平概率（含走水）

设竞彩让球线 `gln`（主队视角，如 -1 表示主让 1），边界 `line = -gln`：

```
主方向（买主）：p = P(M > line)      = 1 − P(M ≤ floor(line))
客方向（买客）：p = P(M < line)      = P(M ≤ ceil(line) − 1)
走水概率（仅整数盘）：p_push = P(M = line)
```

- 半球盘（.5）：无走水
- 整数盘：有走水
- quarter 盘（.25/.75）：需拆两半，本模型**不处理**（返回 null，调用方用保守旧式）

## D. EV 公式

### D1 无走水（欧赔 / 竞彩胜平负 / 亚盘半球）
```
EV = p_model × O − 1
```

### D2 有走水（亚盘整数盘）
```
EV = p_win × O + p_push × 1 − 1        # 走水退本金，等价于 p_win×O + p_push − 1
```
> 注意：竞彩让球盘“让平”算输，不加回 p_push；只有欧亚结算才加。

### D3 项目里 M-04 门控的具体实现
```
1) 去水得 fair（比例法）
2) p = fairProbForPick(fair, side, market, gln)
3) jcEV    = p × O_竞彩 − 1
4) settleEV = p × O_欧亚 + p_push − 1     # 仅 HHAD 整数盘加 push
5) 准入条件：score ≥ 48 且 0.5 ≤ 距开赛小时 ≤ 8 且 竞彩赔率有效 且 欧赔三项有效
6) 放行条件：jcEV < 0（竞彩本身负 EV）但 settleEV ≥ 0（欧亚侧正 EV）
```

## E. 凯利注额

```
b = O − 1
p = 模型胜率
q = 1 − p
f* = (b·p − q) / b
下注额 = ¼ × f* × 本金
f* ≤ 0 → 不下注
```
- 用 1/4 凯利防过拟合
- **无模型概率时 f* 无定义 → 不注**（这是当前开云侧的现状）

## F. 亚盘盘口结算数学（用于算真实盈亏）

设净胜球差 `m = 主 − 客`，买主队让球线 `L`（如 -0.75）：

| 盘口 | 结算 |
|---|---|
| 整数 L（如 -1） | m + L > 0 赢；= 0 走水退本；< 0 输 |
| 半球 L（如 -0.5） | m + L > 0 赢；否则输（无走水） |
| quarter L（如 -0.75 = -0.5/-1） | 拆两半：-0.5 与 -1 分别结算，一半赢一半走水 = **赢半**；一半输一半走水 = **输半** |

**赢半收益**：`stake/2 × (O − 1)`；**输半损失**：`stake/2`。

**示例（孟买城B -0.5/1 @1.85，5 元，净胜 1 球）**：
```
拆 -0.5（赢）+ -1（走水）→ 赢半
收益 = 5/2 × 0.85 = 2.125 ≈ +2.13   ✅ 与平台派彩一致
```

## G. 抽水与保本（开云滚球实测）

| 盘 | 赔率 | Z = Σ1/O | 抽水 | 保本胜率 |
|---|---|---|---|---|
| 独赢 | 1.83 / 1.85 | 1.087 | 8.7% | 54.1% ~ 54.6% |
| 独赢 | 1.80 / 1.80 | 1.111 | 11.1% | 55.6% |
| 篮球独赢 | 1.86 / 1.90 | 1.064 | 6.4% | 52.6% ~ 53.8% |

**结论**：要长期盈利，模型胜率必须显著高于 53~56%，否则就是给抽水打工。

## I. 已知假设与缺陷（必须一起交给对方评估）

1. **独立泊松假设**：忽略两队进球相关性、比赛状态、红牌；Dixon-Coles 低比分修正**未接入**这个 EV 链路。
2. **从欧赔反推 λ/μ 是逆问题**：同一组 1x2 可由多组 (λh, λa) 产生，解不唯一；用 1x2 两点约束拟合两个参数，欠定风险存在。
3. **拟合失败即回退**：err > 0.03 时直接用 1x2 侧概率代替让球概率，会高估让球方向 EV。
4. **quarter 盘未建模**：-0.75/+0.25 这类线在 EV 计算里被跳过。
5. **无模型校准记录**：EV 模型没有做过概率校准曲线（reliability diagram），只有 247 场分档 ROI 的事后统计（EV>0 组 +39%，EV≤0 组 −10%，无欧赔组 −16%）。
6. **样本外未验证**：247 场是单赛季、回测性质，未做严格时间切分样本外检验。
7. **开云侧完全没有模型**：只有抽水计算 + 主观筛选，这是本次亏损的主因。
