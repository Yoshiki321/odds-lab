## 二、v2.0 六维设计（GPT S0 权重落地，满分 100）

权重：**降水22 / 方向确认12 / 模型22 / 历史12 / 风险22 / 价值10**（GPT-6 第1轮建议，v1.8 已挂号推迟项，本次落地）。每维详则：

### 1. 降水/变盘 22
- 量级（0-16）：方向降水分量 D（首盘→当前），D≥0.4→16，0.3→14，0.2→12，0.1→10，0.05→8，>0→6，0→3，<0→0（反向升水=0）
- 形态（0-4，来自 odds_history）：方向侧变盘 1-2 次且 HAD/HHAD 同向降水 → +4；仅一侧 → +2；3+ 次已修正 → 0
- 时间（0-2）：临场（距开赛≤2h）猛降水反而要警惕 → 0~1；早盘慢降 → +2
- 高赔侧降水（让球高赔侧 ≥0.3）→ 计入方向确认源，不重复计分

### 2. 方向确认 12（递减加分，防同源重复）
4 源，`分 = 满格12 / 3源10 / 2源7 / 1源4 / 0源0`：
- 源A：HHAD 低赔侧 = 投注方向
- 源B：HAD 低赔侧 = 投注方向
- 源C：大众支持率侧（supportRate 最高侧）= 方向（getSupportRateV1）
- 源D：欧亚错配（okooo 365 让球线 ≥ 竞彩让球线深度，或与方向同向；无缓存=中立不计）
- 大众与机构背离（大众偏 = 方向但概率偏低）→ 记矛盾不算支持（沿用 v1.1 结论）

### 3. 模型命中 22（完整触发条件，取最高不叠加）
| 模型 | 触发 | 分 |
|------|------|-----|
| M1 P2a_gl1 | 让+1 + 非五大 + 变盘1-2次 + 大众低估让负(asupportRate<asupportRate) + dropSide=A | 22 |
| M2 四维偏差 | 大众偏差 \|eValue\|≥19pp + 历史正 + 赛制无硬伤 | 18 |
| M3 冷门错杀 | 大众低估≥15pp + 赔率2.5-5.0 | 14 |
| 降水规则 | 方向降水≥0.1 且与大众同向 | 12 |
| M5 CRS | 大热场博2个≥8.0高赔比分（娱乐池） | 6 |

### 4. 历史验证 12（真实数据，不再全员 6）
- 联赛基线同向 +4：按联赛 60 天滚动平局率/主客胜率，方向与基线结构一致
- 近期状态 +3：两队近 5 场（PG results+history），方向侧队伍状态占优
- 同形态记忆 +3：命中 model-vault 正样本形态 → 3；首次形态 → 1；已知打脸 → 0
- 打脸记忆 −4：该队/该形态在错误账（TRAP/错杀清单）→ 从 12 扣

### 5. 风险排除 22（从 22 扣，全清单）
陷阱记忆−4 / 深盘(≥2)−4 / 绝对热门让球(HAD≤1.30仍让)−4 / 深盘+方向赔率>1.90−3 / 强强对话−2 / 客场巨热(客胜≤1.30且需赢2球)−2 / 次级低赔让球−3 / 远期>12h−2 / 体力轮换(证据触发)−2 / 平局结构基线−2~−3(R9) / 滚动2天平局率≥35%−3（全局杠杆）。地板 0。

### 6. 赔率价值 10（EV 化，替代区间拍脑袋）
- p_dir = 官方去水概率（getSupportRateV1 probability，缺失回退 HAD 三结果去水）
- EV = p_dir×(odds−1) − (1−p_dir)
- EV≥+8%→10，+5~8→8，+3~5→6，0~3→4，−3~0→2，<−3→0
- 单关可投 +1，仅串关 −1（上限10地板0）
- 低赔买热门天然 EV 为负 → 价值低，倒逼只对有真信息的场给分

### 7. 平局两阶段（R_draw 扩到 5 因子）
平赔集中(0.4/0.3/0.2/0.1) + 让球浅(0.3/0.2) + 主客近(0.3/0.2) + **联赛平局基准(0.1)** + **盘口分歧(0.1，有亚盘缓存时)**。
- ≥0.7 弃投（总分压≤59）· 0.5~0.7 降档候选（≤69）· 受让方豁免
- 全局杠杆：滚动 2 天平局率≥35% → 方向信号降一档置信 + 实单线上移 5 分（写入当日 scores 元数据）
