# 模型库（Model Vault）

> **核心思想：模型矩阵自动分级，命中最强模型→顶格下注；小注搏冷；小注比分。**
> 每个模型独立判定、独立仓位、可回测、可复盘迭代。不下"感觉单"。

完整模型库定义（触发条件、排除条件、历史验证、复盘迭代表）在：
**`data/model/model-vault.md`** — 每次扫盘前读取并逐模型对照。

## 三、核心纪律（不可违反）

1. **单日累计 ≤ 30%**、**单日亏损 ≥ 20% 停手**、连输2单降档
2. **绝不满仓、绝不梭哈**——最强模型 = 顶格10%（起步期），不是梭哈
3. 大众高估让负 = 诱盘（否决M1）
4. 两回合制次回合领先方松懈 = 否决或降级
5. 每场未投注的 → 虚拟注（立场+理由+复盘钩子）

## 三之二、模型否决条件（Veto Rules）与串关纪律（2026-08-29 补丁）

> 以下硬性否决项优先级最高——命中模型但触发否决，**一律废弃该信号，不降级不妥协**。

### M1 第二腿串关纪律（必须同命中 +EV 模型）
- 第二腿**必须同样命中 M2 偏差**（两腿均为 +EV 策略），**严禁任何无模型支持的"稳胆/填坑腿"**
- 若当天无合适第二腿，**强制降级为单场（单关）下注**，绝不为了凑 2串1 强行选场
- 完整触发 → 顶格10%；仅单场 → 按 M1 单场档位

### M2 否决条件（满足任意一条即废弃信号）
1. **机构临场变盘方向与大众偏差买入方向强冲突**（例：M2拟买让负，但机构在临场大幅压低让胜赔率）
2. **临场大众偏差 ≥ 19pp，但机构赔率毫无防范变动**（标准诱盘结构）

### M4 否决条件（满足任意一条即废弃信号）
1. 机构临场变盘方向与"反向搏冷"方向强冲突
2. 临场大众偏差与深盘让-1结构被机构临场变盘修正（机构主动封堵让-1陷阱）
