## 1. 时间可信度分级

**计数口径先说清**（原报告混用了两种计数）：

| 计数方式 | 数量 | 说明 |

按"快照×场次"（594 = 138+231+18+207）：

| 分级 | 数量 |
|---|---|
| strict（odds 更新时间 ≤ 文件名时间，且赛前） | 138 |

| noKickoff（缺开赛时刻） | 18 |
| noResult（历史里无该场赛果） | 207 |

按"独立比赛"（189 = 6+37+82+58+6）：

| 分级 | 数量 |

| strict 与 doubtful 都有 | 37 |

| 仅 noResult | 58 |
| 仅 noKickoff | 6 |
| **可用于主分析的比赛** | **43**（6+37） |

**mtime 不可用的证据**：26 个文件的 mtime 全部比文件名时间晚 **28801 秒（约 8 小时 0 分 1 秒）**，这是整批复制/解压的典型特征，不是逐个采集的痕迹。因此**不再使用 mtime 作为采集证明**，也不再使用 `max(mtime, updateTime)` 作为预测时点。

**文件名时间本身也缺独立证据**。所以 strict 只能理解为"可证明的下界"：内容更新不晚于文件名时间；但"这个文件当时确实被写下"没有第三方记录。

## 2. 训练数据泄漏核查

- 训练只用 `data/history/football/*.json`，条件为 **`matchDate < 预测日`**（保守）。
- **无法证明**：历史文件只有日期没有开赛时刻，因此无法证明"该场在预测时已结束"。跨午夜比赛可能被推迟一天才可用。
- **无法证明**：历史文件是否事后修订（无版本/哈希记录）。
- 因此代码里的按日期过滤 **不等于** 已证明无泄漏；本报告将其列为**未验证假设**。

## 3. 按比赛重算（每场一个预设时点）

**预设规则（先定后用）**：每场取 strict 快照中**距开赛最近且 ≥30 分钟**的那一个；预测时间取**文件名时间**。

| 项 | 值 |
|---|---|
| 进入主分析的比赛 | **43** |
| 开赛时间跨度 | 2026-08-24 02:45 ~ 2026-08-29 19:30（北京时间，5.7 天） |
| 每场快照数 | 最少 1，最多 6，平均 3.2 |
| 距开赛分钟 | 30 ~ 4940 |

**指标定义（与行级不同）**：
- `Brier3 = Σ_k (p_k − y_k)²`，三类求和，范围 0~2
- `LogLoss = −ln p_actual`

| 指标 | 独立模型 | 市场基线 |
|---|---|---|
| Brier3 | **0.5721** | **0.5157** |
| LogLoss | **0.9626** | **0.8808** |

配对差（模型 − 基线）：**+0.0564**；按比赛聚类的 bootstrap（2000 次）95%CI **[+0.0030, +0.1165]**。

**解读边界**：
- 区间下界贴近 0，且未处理"同球队多场"的二级相关 → 只能写"在这批样本上更差"，**不写"显著劣于"**。
- 43 场不是 43 个独立抽样，球队高度重叠。

## 5. 新采集方案（先设计，不补造历史）

**主评估时点**：**T−30 分钟**（与临场决策一致）。
辅助时点：T−24h、T−6h、T−1h（只做辅助分析，不替换主时点）。

**每条记录必须包含**：
- 采集真实时间（本机 UTC+8，存 ISO 与时区）、数据源声称时间、两者差值
- 赛事 ID、联赛、主客队 ID 与名称、开赛时间（含时区）
- 完整赔率：独赢主/平/客、让球线+两侧、大小线+两侧
- 文件 SHA-256、采集结果（成功/失败原因）
- 原始快照**只增不改**，按 `YYYY-MM-DD/HHmmss_<hash8>.json` 存放

**采样窗口与缺失**：
- T−30 允许窗口 **T−35 ~ T−25**；T−24h 允许 ±60min；T−6h/T−1h 允许 ±20min
- 窗口内没采到 → 记 `missing`，**不插值、不事后补写、不改时间字段**
- 同一场同一时点多次采集 → 保留全部，评估时按预设规则取一条并记录选择依据

**评估冻结**：新数据达到预先设定的最小样本（建议 ≥300 场且 ≥3 个月）后，按冻结的时点与切分规则评估一次；不得看完测试集再换时点或换模型。

## 6. 结论

**现有时间证据不足以做严格样本外评估。**
43 场全部依赖"文件名时间"这一无独立证据的假设，训练集仅有日期。因此：
- 可以说的：在这个有缺陷的样本与这套简单泊松模型上，表现不如同一快照的去水基线；
- 不能说的：模型优劣的普遍结论、显著性、任何可盈利推断。

要得到可信结论，必须先按第 5 节采集带真实时点的新数据。在采集到位前，不修改任何时间字段让数据"通过"测试。
