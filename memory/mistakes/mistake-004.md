# 错误 004 — 分析维度不足

## 发生时间
2026-08-24 首次投注时

## 错误的描述
投注分析仅覆盖了赔率快照、支持率、实力对比、让球合理性、风险 5 个维度，遗漏了：
1. **赔率变化追踪**：没有追踪赔率从开盘到临场的走势
2. **冷门价值评估**：6场全部投热门，没有主动评估冷门是否被错杀
3. **体力/伤停核查**：只查了赛程场次数，没查赛程密度和关键球员
4. **变盘监控**：没有监控赔率变化，巴萨客胜1.22→1.20的持续下调（热度信号）被忽略

## 根本原因
1. **分析框架不完整**：strategy.md 中的分析框架只有5个维度，缺少这4个关键维度
2. **过度依赖静态数据**：赔率快照只能反映"此刻"，看不到"趋势"
3. **缺乏冷门意识**：默认"热门=安全"，没有理解低赔≠低风险
4. **疲劳/伤停是盲区**：官方API没有直接伤停数据，但赛程密度可以从联赛数据推算

## 如何避免
- **R4: 8维分析框架**。strategy.md v2 已升级，每场必查赔率变化/冷门价值/体力伤停/变盘信号
- 新手投注前先跑数据：`getFixedBonusV1` 查赔率变化 + 联赛数据查赛程密度
- 热门赔率≤1.50 且大众支持率≥85% 的场次，标记为"大热警戒"，单独评估

**Why:** 赔率是动态的，变化趋势比单点快照更有信息量。冷门不是瞎搏，是有数据支撑的逆向选择。
**How to apply:** 每场分析档案必须包含 8 维。核对方法：看 analysis 档案里是否有 `oddsHistory`、`fatigue`、`upsideValue` 字段。
